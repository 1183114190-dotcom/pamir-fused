# 《花儿为什么这样红》本地互动课件（新版内容 × 旧版视觉）

这是以新版 HTML 的五个教学场景和 JavaScript 功能为主体、迁移旧版视觉语言后的离线课堂课件：

1. 初步判断：原曲主题片段播放器与“旋律、节奏、调式、音色”初步猜想记录。
2. 音色实验：民族化音色与钢琴、弦乐等西洋音色的 A/B 对照及三项判断。
3. 节奏实验：贴近原作气质与现代流行节奏的 A/B 对照及判断记录。
4. 旋律与调式：等待教师现场钢琴示范，逐步点亮四个音乐要素并最后呈现共同作用的结论。
5. 我是音乐创作者：四组变量选择和小组创作方案展示。

视觉迁移包括旧版的深色高原背景、衬线标题、红金强调色、导航胶囊、横向播放器、创作蓝图卡片、页面留白和大屏舞台比例。新版的音频准备、全屏、上一环节/下一环节、sessionStorage 状态、判断记录与离线音频逻辑均保留。

## 使用方式

解压后双击 `index.html`。无需服务器、安装依赖或联网。课件按 1920×1080 固定舞台设计，会自动缩放到 16:9 浏览器窗口；可点击右上角“全屏”或按 F11。

课件没有内置真实音频。点击右上角“音频准备”，为五个音频分别选择本地文件：

- `original.mp3`：原曲主题片段
- `timbre-a.mp3`：音色实验 A，民族化音色
- `timbre-b.mp3`：音色实验 B，钢琴、弦乐等西洋音色
- `rhythm-a.mp3`：节奏实验 A，贴近原作气质
- `rhythm-b.mp3`：节奏实验 B，现代流行节奏

也可以将文件按以上名称放入 `assets/audio/` 后打开课件。课堂前请完整试听。

## 课堂操作

初步判断页先播放原曲主题片段，学生表达后教师点击四个要素记录猜想。音色实验与节奏实验各自播放 A/B，教师选择课堂判断。旋律与调式页没有 AI 音频，教师现场钢琴示范后逐步点亮四项要素，四项全部点亮后才可呈现归纳。创作页根据小组讨论点击速度、情绪、配器、民族音乐语言，四项完成后点击“展示完整方案”。

任意播放器同一时刻只播放一段；切换场景会暂停音频。当前课堂记录保存在 sessionStorage，刷新后保留；“清空本轮课堂记录”会重置猜想、判断、要素发现和创作方案，但保留已选择音频。

## 项目结构

- `index.html`：课件入口与固定舞台。
- `css/style.css`：新版五页布局与旧版视觉系统。
- `css/fonts.css`：随包提供的离线中文字体声明。
- `js/app.js`：新版课堂状态、音频播放、页面导航和交互逻辑。
- `assets/images/pamir-mountains.svg`：迁移自旧版的本地山体装饰。
- `assets/fonts/`：随包提供的本地字体文件。
- `assets/audio/`：教师音频放置目录。
